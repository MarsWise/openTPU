# Порядок запуска (16.11.2026)

Все команды — из PowerShell в `C:\myOpenTPU\_claude\r8\`. Ничего не грузится в FPGA без вашего «yes».

## А. Текущая сборка `1a77396a` (исправление MXU)

1. Дождаться конца сборки. Итог: `C:\myOpenTPU\openTPU-r8\build\vivado-r8-m8-133.33-1a77396a\reports\SUMMARY.txt`.
   Если `otpu.bit` нет — тайминг не закрыт, грузить нечего: пришлите `SUMMARY.txt`.
2. `.\r8_load_newest.cmd` — покажет, какую сборку нашёл, спросит «yes», загрузит по JTAG (не во флеш).
3. `.\r8_restore_pcie.cmd` — вернуть PCIe на хосте (спросит пароль sudo).
4. `.\r8_build_c2.cmd` — запустить сборку C2 (несколько часов). Только после шага 2: загрузка и сборка обе используют Vivado.
5. `.\r8_all_tests.cmd` — все тесты платы подряд, 6–9 часов, без вопросов. Логи: `runs\<дата-время>\`.

## Б. Сборка C2 (ускорение Bonsai)

1. Дождаться конца сборки C2 (появится новая папка `build\vivado-r8-m8-133.33-<номер>`).
2. Дождаться конца `r8_all_tests.cmd` из части А, если он ещё идёт.
3. `.\r8_load_newest.cmd` → «yes».
4. `.\r8_restore_pcie.cmd`.
5. `.\r8_all_tests.cmd`.

## Что прислать

Папку `runs\<дата-время>\` после каждого прогона (в ней `steps.txt` и логи шагов) и `SUMMARY.txt` каждой сборки.

## Отдельные команды

| Команда | Что делает | Время |
|---|---|---|
| `.\r8_models.cmd` | какая прошивка на плате, счётчики ECC | 1 мин |
| `.\r8_card_tests.cmd` | инструкции, KV, Diffusion, SmolVLA, YOLOX, vLLM, Bonsai | 4–6 ч |
| `$env:PASSES=4; .\r8_ddr_check.cmd` | длительная проверка DDR | 2–3 ч |
| `.\r8_needle.cmd` | Needle int8 и CQ4 | 10 мин |
| `.\r8_llm.cmd lfm3` (`minicpm5`, `granite`) | LLM против эталона | 1–2 мин |
| `.\r8_speed.cmd` | скорость шести LLM | 10 мин |
| `.\r8_chat.cmd bitnet` | чат | — |

Вернуть прежнюю прошивку: `.\r8_load.cmd` (без аргументов — `2c800a8f`) → `.\r8_restore_pcie.cmd`.

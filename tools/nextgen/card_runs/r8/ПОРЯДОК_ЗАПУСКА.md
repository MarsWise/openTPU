# Порядок запуска (17.11.2026)

Все команды — из PowerShell в `C:\myOpenTPU\_claude\r8\` (`cd C:\myOpenTPU\_claude\r8`).
В FPGA ничего не грузится без вашего «yes». Сейчас идут две сборки:

| Сборка | Папка в `C:\myOpenTPU\openTPU-r8\build\` | Что в ней |
|---|---|---|
| `1a77396a` | `vivado-r8-m8-133.33-1a77396a` | исправление MXU |
| `c969ca4c` (C2) | `vivado-r8-m8-133.33-c969ca4c` | исправление MXU + ускорение Bonsai + дочистка тайминга |

Сборка закончилась успешно, если в её папке есть `otpu.bit`. Итог тайминга — `reports\SUMMARY.txt`.

## А. Сборка `1a77396a`

1. Есть `otpu.bit` → шаг 3. Нет → шаг 2.
2. Дочистить без пересборки (около часа): `.\r8_signoff_resume.cmd`. Пока идёт сборка C2, он не запустится —
   тогда пропустите часть А и ждите C2.
3. `.\r8_load_newest.cmd 1a77396a parallel` → «yes». (`parallel` нужен, пока работает сборка C2.)
4. `.\r8_restore_pcie.cmd` (пароль sudo).
5. `.\r8_all_tests.cmd` — все тесты, 6–9 часов. Логи: `runs\<дата-время>\`.

## Б. Сборка C2 `c969ca4c`

1. Дождаться конца сборки и конца тестов части А.
2. Есть `otpu.bit` → `.\r8_load_newest.cmd c969ca4c` → «yes». Нет → `.\r8_signoff_resume.cmd vivado-r8-m8-133.33-c969ca4c`, затем загрузка.
3. `.\r8_restore_pcie.cmd`.
4. `.\r8_all_tests.cmd`.

На прошивке C2 шаг скорости сам гоняет Bonsai дважды: с ускорением и без него (`OTPU_GQ4=0`) — это и есть замер выигрыша.

## Что прислать

`SUMMARY.txt` каждой сборки и папку `runs\<дата-время>\` после каждого прогона (в ней `steps.txt` и логи).

## Отдельные команды

| Команда | Что делает | Время |
|---|---|---|
| `.\r8_models.cmd` | какая прошивка на плате, счётчики ECC | 1 мин |
| `.\r8_card_tests.cmd` | инструкции, KV, Diffusion, SmolVLA, YOLOX, vLLM, Bonsai | до 6 ч |
| `$env:PASSES=4; .\r8_ddr_check.cmd` | длительная проверка DDR | до 1 ч |
| `.\r8_needle.cmd` | Needle int8 и CQ4 | 2 мин |
| `.\r8_llm.cmd lfm3` (`minicpm5`, `granite`) | LLM против эталона | 1–2 мин |
| `.\r8_speed.cmd` | скорость LLM (можно `.\r8_speed.cmd bonsai`) | 10 мин |
| `.\r8_chat.cmd bitnet` | чат | — |

Вернуть прежнюю прошивку: `.\r8_load.cmd` (без аргументов — `2c800a8f`) → `.\r8_restore_pcie.cmd`.

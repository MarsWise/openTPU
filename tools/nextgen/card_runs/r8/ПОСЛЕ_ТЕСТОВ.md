## Шаг 1. Отчёт размещения (только Vivado)

Старое окно `r8_place_report.cmd` закрыть (Ctrl+C, «y»). Затем

    .\r8_place_report.cmd

~4–5 минут на сборку. Пишет папки `place_*`; разбор делаю я.

## Шаг 2. Длинная проверка C2 (на плате сейчас C2, ~25 минут)

Критерий: ECC 0 / 0 во всех четырёх проходах.

## Шаг 3. Если шаг 2 чистый — все тесты заново

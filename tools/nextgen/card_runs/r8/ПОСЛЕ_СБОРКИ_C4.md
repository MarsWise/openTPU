# После сборки C4 (`r8_build_c4.cmd`, коммит 508da1c6: C3 без T5 / BIN / BIN GSC)

Все команды из `C:\myOpenTPU\_claude\r8`. Окна не закрывать; прервать — потом `.\r8_stop.cmd`.

## 0. Сборка закончилась?

В конце окна — `WNS` и `WHS` и `hash=37f51889`. Если оба ≥ 0, есть
`C:\myOpenTPU\openTPU-r8\build\vivado-r8-m8-133.33-508da1c6\otpu.bit`.
`=== exit 1` при этом бывает и у хорошей сборки (как у C3): смотреть на WNS / WHS и otpu.bit.
Нет битстрима — прислать конец лога.

## 1. Площадь против C3 (секунды, без Vivado, на карту ничего не грузится)

    .\r8_area_compare.cmd 508da1c6

Таблица LUT / LUTRAM / FF / BRAM / DSP по узлам C3 → C4 и тайминг обеих сборок; сохраняется
в `r8_area_508da1c6.txt`. Главная строка — `u_mxu.(u_mxu)`: там декод весов (в C3 16 715 LUT).

## 2. Всё на карте одной командой (~9–11 ч)

    .\r8_after_build.cmd 508da1c6

загрузка (ввести `yes`) → PCIe (пароль sudo) → `r8_ddr_diag` → `r8_ddr_split` 3 прохода →
`r8_ddr_check` 4 прохода → вердикт `gate.txt` → `r8_all_tests` (все модели).

| Идентичность (`r8_card_check`) | CFG_HASH 37f51889; CAPS2 без td5 / tbin / tbgsc, остальные r8-биты есть; «the area build refuses TMM T5 / BIN / BIN GSC» — PASS |

Memory deep dive · bank, channel, beat

Two independent address decoders: logical TMEM words map by modulo LANES; logical DRAM data are interleaved over 64-byte beats and optionally hashed across physical channels. Uses the formulas documented in the native DRAM adapter.

Reproducibility and source links

This atlas pins clickable implementation files to the feature branch commit it was read against, so a later refactor cannot silently change what a diagram links to.

Limitations and acceptance

  • The deep zoom descends to DSP48E1 logical blocks and FPGA LUT/FF/BRAM/CARRY4 concepts. It does not reconstruct transistor nets or physical transistor layouts from SystemVerilog.
  • The code is a visual explanation; not a new RTL synthesis, Verilator simulation, firmware build or board run.
  • The m4 target figures are sourced from the pinned target configuration. The m8 architecture can be inspected separately, but a timing-closed bitstream is not presumed.
  • The physical chip layout, clock tree, pblock placement and gates-after-synthesis would require actual Vivado placement/routing files for the specific bitstream.
  • The original ET-SoC-1 page served as an inspiration only. This interface is independently implemented using openTPU's publicly accessible own source.

What this project actually documents

The board is a Xilinx Kintex-7 XC7K480T with two 2 GiB DDR3 channels. Its core combines a scoreboard sequencer, DMA, INT8/FP4/ternary matrix datapaths, FP32 vector units, local tensor memory and a quantizer. This page is not a fabricated chip layout or a transistor extraction: source-backed block diagrams and textbook-level CMOS/physical views are marked separately.

01 · Architecture, not guesses

Board configuration, the RTL module hierarchy and exact memory mapping are linked directly to a pinned source revision. Unsupported placements are clearly designated illustrative.

02 · Real performance, separated

BitNet's measured throughput is not the MXU arithmetic peak. Model-dependent DDR traffic, PCIe overhead and INT8/FP4/TMM format differences are never presented as interchangeable.

03 · Deep physical zoom

The MXU's actual DSP48E1 primitives can be followed to M, P and PCIN/PCOUT. Below that, Boolean gates, SRAM cells, transistors and atomic structures are explanatory models, not recovered Xilinx schematics.

Evidence, limits, and scale

The source diagrams are logical and interactive. Xilinx implementation results, exact BRAM/DSP placement, post-route wire lengths and gate-level switching are not accessible through the source alone. The physical scale continuation uses public semiconductor concepts and estimates and is labelled textbook wherever it stops describing verified openTPU RTL. No performance animations are claimed to be measurements: the actual timeline belongs to otpu-lens.

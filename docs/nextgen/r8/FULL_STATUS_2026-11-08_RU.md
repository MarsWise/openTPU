# openTPU r8: что сделано и что осталось — по всем ТЗ, пунктам и моделям (8.11.2026, вечер)

Заменяет сводки `TZ_FULL_STATUS_2026-11-01`, `GAP_R8_2026-11-01` и `RTL_TODO_R8_2026-11-01`, а по моделям — `MODELS_TODO_2026-11-08`. Подробности замеров — в `STATUS_2026-11-08_RU.md`, разделы 2.1–2.12.

**Учтённые ТЗ:**

- исходное ТЗ проекта, части 1–24;
- `MASTER_PLAN_R8`, `EXPANSION_PLAN 1.11`, `TZ_ADDENDUM 1.11` (направления N1–N9);
- `ALL_MODELS_RTL_CHECK 1.11`;
- указания пользователя:
  - только m8, m4 не нужна;
  - MSI отложить;
  - все модели — целиком на плате;
  - BFLY / AFF / CSWP не отключать ради площади;
  - LFM3-1.7B — поддерживать.

**Уровни доказательств** не смешиваются:

| Уровень | Что значит |
|---|---|
| CODE | только код |
| ISA | симулятор ISA |
| RTL | Verilator 5.046, RTL == ISA бит в бит |
| FRAME | эталон на CPU |
| SYNTH / ROUTE | Vivado: синтез / разводка |
| PHYS | на плате |

**Статусы:** ✅ сделано на указанном уровне, 🟡 частично, ❌ не сделано, ⏸ отложено.

**Ветка** `MarsWise/openTPU:feature/r7-fpga`:

- запушено: `ac61805`;
- локально: `10bb8b8` (правка площади MXU) — пушится после RTL-проверки;
- PR #1 — open / draft / не слит.

## 0. Главное

1. **Набор аппаратных операций по ТЗ собран.** Все обязательные RTL-блоки (A1, A2, C1, C3, C8, C10, C11, R3, R4, R6, CSWP) есть в RTL и прошли RTL == ISA. Для перечисленных в ТЗ моделей новых операций не требуется. Это не значит, что аппаратная работа закончена:
   - площадь;
   - sign-off;
   - замеры на плате могут потребовать правок: Bonsai GSC — C2, LSTM, SD 1.5 int16.
2. **r8 ещё ни разу не была на плате.** На плате проверено только старое: r5, greedy. Все r8-функции — максимум RTL.
3. **Синтез r8 `3d416ed0` (пользователь, 8.11)** — SYNTH:
   - LUT 244 960 (82,0 %, было 90,5 %);
   - WNS core_clk 133,33 МГц: +0,349 нс;
   - защёлок нет, T4 в BRAM.

   Полная сборка (place / route / sign-off) не запускалась.
4. **Verilator 5.046** нужен для любой RTL-проверки:
   - в контейнере Claude: только 5.020, он не разбирает `otpu_mxu.sv`;
   - на хосте 157: не найден;
   - ставится в WSL скриптом `C:\myOpenTPU\_claude\install_verilator_5046.cmd`.

### 1.3 Оговорки к закрытым замером пунктам

- **C9 (int16)** — проверен один сид, 256 px, FRAME. Нужно повторить на 512 px и нескольких сидах (SD 1.5), а также для Kokoro и EnCodec.
- **LSTM** — замер только при H = 256, один шаг. Шаг упирается в поток весов W_hh. Для других размеров и длинных последовательностей вывод не доказан.
- **Bonsai** — наличие TMM не означает скорости. Решение по C2 — только после замера на r8.

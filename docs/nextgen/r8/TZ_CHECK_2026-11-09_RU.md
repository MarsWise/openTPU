## Итог в пяти строках

1. **RTL-набор по ТЗ собран целиком** и проверен на RTL. На **плате r8 ещё не была**: PHYS есть только у r5.
2. **Сборка r8 не закрыта.** a4138552 не сошлась (core WNS −1.23 ns). Исправленная 23941ede прошла синтез: LUT −7.8k, core WNS +0.65 ns. Полную разводку ещё не запускали.
3. **FPGA-only закрыт не полностью.** Остались:
   - исполнитель графа на устройстве;
   - планировщик памяти для нескольких моделей;
   - единый аудит «хост ничего не считает»;
   - первый токен MTP;
   - позиции LFM2;
   - MoE без хоста;
   - многослотовый vLLM.
4. **Модели.** Реальные веса на плате: Qwen3, LFM2, BitNet, Bonsai 4B — только на r5. Остальные (LFM3, MiniCPM5, Granite, Ouro, Dory, Cactus, PaddleOCR, Kokoro, MusicGen, SD 1.5) от L0 до L2, без PHYS. YOLOX, MiniCPM-V, SmolVLA, Diffusion — ISA, полного реального графа на плате нет.
5. **Документация и регрессия.** Полный набор тестов после r8-изменений не прогонялся до 9.11. Сейчас идёт ISA-часть, см. раздел 25. `docs/nextgen` (PROGRESS, MODEL_COMPATIBILITY, VERIFIED_RESULTS.csv, OPERATOR_COVERAGE_MATRIX) не обновлены под r8.

## Что сделано с прошлой сводки (8.11 → 9.11)

- **Verilator 5.046:** контейнер и WSL. Выполнены все отложенные RTL-проверки r8: kv6-токен, k6v6-токен, CQ / T5 / GRQ / GSC / QST6, CSWP.
- **6-битный V в графе внимания (k6v6).** Без нового RTL: QST Q6T, P'·V как TMM CQ2 GRQ, позиции в state words 48–50. Токен на модели платы — RTL == ISA.
- **Хост-часть для r8:**
  - проверки инструкций и KV на карте против ISA;
  - загрузка по JTAG (volatile, только с «yes»);
  - восстановление PCIe;
  - прогон модельных тестов.
- **Ошибка хоста в wait-записях VOP AFF** (на WAITC-железе — неверный результат без ошибки) — исправлена, есть тест.
- **Тайминг / площадь:**
  - разобран провал a4138552;
  - таблица CQ в LUT RAM по позициям;
  - T5 — табличный;
  - регистр в `otpu_mem_ch`;
  - синтез: −7.8k LUT, core WNS +0.65 ns.
- **LFM3:** спецификация по конфигу, эталон, 3 теста.
- **Upstream:** сверено 9.11 (выше).
